# リエゾン・サービス仕様書

---

## 1. サービス概要

実スペースの展覧会と連動したオンライン作品展示・販売サービス。  
展覧会の会期が短く、遠方や都合が合わない人にも展示を見て、興味を持ち、購入してもらえる**機会ロストへの補完**が目的。

| | リエゾン | リエゾンプラス |
|---|---|---|
| オンライン作品展示 | ✅ | ✅ |
| 作品販売 | ❌ | ✅ |
| 料金 | 無料 | 展示無料・販売手数料あり（推奨10%(少額商品20％)） |
| 申込条件 | クリエイター機能申込ユーザー（自動利用可） | 上記＋リエゾンプラス機能申込 |

---

## 2. 利用者・出品条件

- **利用者**：クリエイターユーザーのみ（初期導入）
- **出品者**：作品の作家本人のみ（真正性確保のため）
- 次フェーズ以降にギャラリーユーザーへの拡大を検討

---

## 3. 展示期間

### リエゾン
- 展覧会と同期間

### リエゾンプラス（3つから選択）
1. 展覧会と同期間
2. 会期終了後〜2週間
3. カスタム（会期開始日〜終了後2週間の間で任意の期間を選択）

### リエゾン期間外の作品
- クリエイターページから引き続き閲覧可能

---

## 4. 展示仕様（初期導入）

- 展覧会に紐づく形で開設
- 作品点数：制限なし
- 対応形式：画像のみ（動画なし）
- 同時複数点購入：非対応（1取引1点）

---

## 5. 販売フロー（会場優先型）

サービスの目的は「機会ロストへの補完」であり、会場での販売を最優先とする。

```
【購入者】
オンラインで購入申込
    ↓
申込中キューに追加（追加申込も受付継続）
    ↓
会期終了まで保留
    ↓
会期終了後に在庫確認
    ├── 在庫あり → 申込順に購入プロセスへ進む
    └── 在庫なし → 申込キャンセル通知
```

### 設計の意図
- 会期中は会場での販売を優先
- ギャラリーとの関係性を保護
- キャンセルによる機会ロスをキュー方式で最小化
- オンライン購入が会場在庫と競合しない設計

---

## 6. 購入申込優先キュー型

- 「申込中」状態でも追加申込を受け付ける
- 複数人が同一作品にキューイン可能
- 会期終了後、キュー順（申込順）に在庫確認→購入プロセスへ
- キャンセルが発生した場合は次のキューへ自動移行

---

## 7. 作品の販売状態（5種類）

リエゾン・リエゾンプラス共通の販売状態。管理方式のみ異なる。

| 状態 | 説明 | リエゾン（管理） | リエゾンプラス（管理） |
|---|---|---|---|
| 販売中 | 購入申込を受付中 | クリエイターが手動設定 | クリエイターが手動設定 / システムが自動設定 |
| 申込中 | 1件以上の申込あり。追加申込も受付 | クリエイターが手動設定 | **システムが自動設定**（申込受付時） |
| 売却済 | 販売確定済み | クリエイターが手動設定（会場・オンライン問わず） | クリエイターが手動設定（会場売却時）/ **システムが自動設定**（オンライン販売確定時） |
| 要問合せ | 個別対応が必要な作品 | クリエイターが手動設定 | クリエイターが手動設定 |
| 非売品 | 展示のみ・販売しない | クリエイターが手動設定 | クリエイターが手動設定 |

### 管理方式のまとめ
- **リエゾン**：すべてクリエイターの手動管理（販売機能なし・展示のみ）
- **リエゾンプラス**：購入申込・オンライン販売確定のタイミングでシステムが自動更新。会場売却・要問合せ・非売品はクリエイターが手動設定。

## 8. 匿名配送（必須要件）

### 背景
展覧会会場でもストーカー等の被害に遭っているクリエイターが存在する。  
クリエイターが安心して利用できることがサービス成立の前提条件。

### 仕様
- 配送方法として匿名配送を選択肢として提供（必須）
- クリエイターの個人情報（住所・氏名）を購入者に開示しない
- 匿名配送対応の配送業者との連携が必要

---

## 9. PWA対応（必須要件）

### 背景
- 個展なびはスマホネイティブアプリの開発予定なし
- リエゾンプラスでは、クリエイターがリアルタイムに対応する場面が多い
  - 購入申込通知
  - 会場売却時の販売状態手動更新
  - 取引対応・メッセージ返信

### 必要な機能
- プッシュ通知（購入申込・取引状況の変化をリアルタイム通知）
- ホーム画面への追加（アプリライクな操作性）
- オフライン対応（会場内でのネットワーク不安定時への対応）

## 10. 作品画像仕様

|---|---|---|

| カラーモード | RGB | RGB |

### 表示仕様（システムが自動処理）
- アップロード後、長辺1,200pxに自動リサイズ
- ウォーターマークを自動付与
- WebP形式に自動変換（表示高速化）
- オリジナルファイルは保存しない（プライバシー保護）

## 11. コピーガード実装仕様

### 基本方針
オンラインでの完全なコピー防止は技術的に不可能。  
「**悪用コストを上げる**」ことを目標に、低コスト・実装簡単な対策を組み合わせる。

### ① 表示解像度の制限（最重要）
- アップロードされた画像はサーバーサイドで**長辺1,200px以下**に自動リサイズして表示
- 原版（高解像度）はクリエイターの手元のみに保管
- スクリーンショットを撮られても印刷・商用利用に耐えない解像度に留める
- 実装：Sharp（Node.js）/ ImageMagick / Cloudinary等で自動処理

### ② ウォーターマーク自動付与（静的）
- アップロード時にサーバーサイドで半透明ウォーターマークを自動合成
- 表示内容：`© [作家名] / koten-navi.com`
- 位置：画像中央（薄め）＋右下（やや濃いめ）の2点配置を推奨
- 実装：Sharp / ImageMagickで対応可能・追加費用ほぼゼロ
- クリエイターが任意でOFF設定できるオプションも検討

### ③ 動的ウォーターマーク（推奨・追加対策）

閲覧者のユーザーID・日時を画像に動的に埋め込む。見た目への影響を最小化しつつ、悪用発覚時に「誰から流出したか」を特定できる。

**仕組み**
```
ユーザーがリエゾンページを閲覧
    ↓
サーバーが「ユーザーID + 閲覧日時」を取得
    ↓
Sharpで画像にテキストを合成してレンダリング
    ↓
合成済み画像をブラウザに返す（オリジナルは保存しない）
```

**実装コード例（Node.js + Sharp）**
```javascript
const sharp = require('sharp');

async function addDynamicWatermark(imagePath, userId, viewedAt) {
  const watermarkText = `ID:${userId}  ${viewedAt}`;

  const svgText = `
    <svg width="1200" height="100">
      <text
        x="600" y="60"
        font-family="Arial"
        font-size="18"
        fill="rgba(255,255,255,0.35)"
        text-anchor="middle"
        transform="rotate(-30, 600, 50)"
      >${watermarkText}</text>
    </svg>
  `;

  return await sharp(imagePath)
    .resize({ width: 1200, withoutEnlargement: true })
    .composite([{ input: Buffer.from(svgText), gravity: 'center' }])
    .webp({ quality: 82 })
    .toBuffer();
}
```

**ゲスト（未ログイン）の扱い**

| 閲覧者 | ウォーターマーク内容 |
|---|---|
| ログイン済みユーザー | `ID:U12345  2026-03-02` |
| ゲスト（未ログイン） | `GUEST  2026-03-02 14:32` + IPアドレスの末尾 |

**キャッシュ設計（負荷対策）**
- キャッシュキー：`artwork_id + user_id + 日付（時間単位）`
- 有効期限：1時間程度
- 保存先：Redis またはファイルキャッシュ
- 同一ユーザー・同日は再生成しない設計で負荷を抑制

**費用：Sharpはオープンソース・無料。追加費用ゼロで実装可能。**

### ④ 右クリック・長押し禁止（CSS/JS）

```css
img {
  pointer-events: none;
  user-select: none;
  -webkit-user-drag: none;
}
```
```javascript
document.addEventListener('contextmenu', e => {
  if (e.target.tagName === 'IMG') e.preventDefault();
});
document.addEventListener('touchstart', e => {
  if (e.target.tagName === 'IMG') e.preventDefault();
}, { passive: false });
```
実装コスト：ほぼゼロ。初歩的なダウンロードを抑止。

### 対策の組み合わせまとめ

| 対策 | 効果 | 実装コスト |
|---|---|---|
| 表示解像度を1,200px以下に制限 | 高品質コピーの抑止 | 低（既存ライブラリ） |
| ウォーターマーク自動付与（静的） | 出所の明示・悪用の心理的抑止 | 低（既存ライブラリ） |
| 動的ウォーターマーク（ユーザーID埋め込み） | 流出元の特定・追跡・心理的抑止 | 低（Sharp + キャッシュ） |
| 右クリック・長押し禁止 | 初歩的ダウンロードの抑止 | 最低（数行のコード） |

## 12. クリエイター向け・作品画像準備ガイド

> このガイドはP70リエゾンガイド（作品出品ガイド）に掲載する内容の原稿です。

### はじめに
作品の魅力を正確に伝える画像は、オンラインでの購入判断に直結します。  
アンケートでは「実物との色味・質感の違い」が購入をためらう最大の理由でした。  
このガイドを参考に、できるだけ実物に近い画像を準備してください。

### 推奨スペック

| 項目 | 推奨値 |
|---|---|
| 長辺 | 2,000px以上 |
| 形式 | JPEG（品質80以上）または PNG |
| サイズ | 10MB以下 |
| 色味 | 自然光または昼白色ライトで撮影 |

### スマートフォンでの撮影方法

#### iPhone の場合
1. **カメラ設定を確認する**
   - 設定 → カメラ → フォーマット → 「高効率」ではなく「**互換性優先**」に設定
   - これでJPEG形式で保存されます
2. **撮影モードは「写真」**
   - ポートレートモードは背景がぼけるため不向き
3. **グリッド線を表示する**
   - 設定 → カメラ → 「グリッド」をオン
   - 作品が画面に対して水平・垂直になるよう合わせる

#### Android の場合
1. **解像度を最大に設定する**
   - カメラアプリの設定 → 解像度 → 最大サイズを選択（12MP以上推奨）
2. **撮影モードは「通常」または「プロ」**
   - 「ポートレート」「ナイト」モードは避ける

### 撮影環境の準備

#### 照明
- **自然光が最適**：曇りの日の窓際が最も色が正確に出やすい
- 直射日光は避ける（反射・色かぶりの原因）
- 室内灯を使う場合は「**昼白色（5000K）**」のLEDライトを推奨

#### 反射・映り込みの防止
- 油彩・アクリル・ガラス額などは光沢があり反射しやすい
- 撮影者自身が映り込まないよう、斜め45度から撮影
- どうしても反射する場合はスマホ用偏光フィルター（PLフィルター・1,000〜3,000円程度）の使用を検討

#### 背景
- **白または薄いグレーの無地**が最適
- 床や壁に直接立てかけるか、イーゼルを使用

### 撮影のポイント

- カメラを作品に対して**真正面・垂直**に構える（斜めに撮ると台形に歪む）
- 上下左右に少し余白を持たせて撮影し、後でトリミング
- **複数枚**撮影する：全体像（必須）＋細部アップ・厚み・額装全体像

### 作品ジャンル別のポイント

| ジャンル | ポイント |
|---|---|
| 平面作品（油彩・アクリル・水彩・版画・イラスト） | 照明の角度を工夫して反射を避ける。大作は分割撮影後に結合も可 |
| 立体作品・工芸（陶芸・金工・ガラスなど） | 正面・側面・上面の3方向から撮影推奨。白布や白紙を背景に |
| 写真作品 | プリント面の反射に注意。可能であれば額から出して撮影 |
| 書道 | 斜め光を避け、均一な照明で撮影 |

### 色味の調整（無料アプリ）

**フィルターの過度な使用は実物との乖離につながるため避けてください。**

| アプリ名 | 対応OS | 特徴 |
|---|---|---|
| Lightroom Mobile | iOS / Android | 色温度・露出の細かい調整が可能 |
| Snapseed | iOS / Android | 直感的に使えるGoogleのアプリ |
| VSCO | iOS / Android | 色味の補正に特化 |

調整項目：露出（明るさ）・色温度（色かぶり補正）・コントラスト（上げすぎない）

### アップロード前のチェックリスト

- [ ] 長辺が2,000px以上ある
- [ ] 作品全体が画角に収まっている
- [ ] 歪み・傾きがない（または補正済み）
- [ ] 反射・映り込みがない
- [ ] 色味が実物に近い
- [ ] 背景に余計なものが映っていない
- [ ] ファイルサイズが10MB以下
- [ ] JPEG または PNG 形式で保存されている

### よくある質問

**Q. スマホのカメラで十分ですか？**  
A. 現在のスマホカメラは十分な性能があります。上記のポイントを守って撮影すれば問題ありません。

**Q. 作品にウォーターマーク（透かし）が入りますか？**  
A. はい、著作権保護のためシステムが自動で入れます。非表示にしたい場合は設定から変更できます。

**Q. RAW形式での撮影・アップロードはできますか？**  
A. 現在はJPEG/PNGのみ対応しています。RAWで撮影した場合はJPEGに変換してアップロードしてください。

**Q. 作品画像の著作権はどうなりますか？**  
A. 著作権はクリエイターに帰属します。個展なびは展示・販売目的での利用のみ行います。
