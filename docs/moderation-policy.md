# 問題報告・削除依頼の対応方針（事務局向け・内部用）

2026-09-27 策定。2026-10-08 に P60-13（理由の一覧 `REPORT_REASONS`）・P60-14・P60-16・P90-9（RP・FX のテンプレート）・F-03A の【至急】と突き合わせ済み（ずれは対象の種類の書き方と P60-16 の見出し名だけで、直した）。問題報告（P60-13）・修正依頼（P60-14）・掲載の対象者からの削除依頼に、事務局がどう対応するかの**判断の基準**。これまでの運用を明文化したもの。

- 本ファイルは**内部用**（事務局・後工程向け）。サイト上に公開する「対応方針」は、本ファイルを要約して P60 系のガイドに載せる（後日）。
- 法令に関わる部分（権利侵害の申し立て・送信防止措置など）は概要のみ。**実際の運用前に専門家に確認する**。

---

## 1. 基本の考え方

1. **真偽を裁くのではなく、決めた手順どおりに処理する。** 1件ずつ事実を調べ尽くすことはできない。運営者に求められるのは、問題を知らせる道があり、届いたら決まった手順で対応すること。手順が一貫していて記録が残っていれば、それが正当な対応。
2. **優先度は報告の書き方ではなく、理由で決める。** 「至急」「すぐに」と書かれていても優先度は上げない。選ばれた理由（P60-13 の選択肢）で決まる。
3. **取り返しのつかない被害を先に防ぐ。** 非公開は元に戻せるが、被害は戻らない。身の安全・プライバシーに関わるものは、確認より先に一時非公開にする。
4. **当事者間の揉め事には入らない。** 報告者と掲載者の関係や経緯は、推測できても判断の材料にしない。判断は「掲載内容が事実か」「権利を侵していないか」「規約に反していないか」だけで行う。
5. **できないことは最初から正直に伝える。** 事実関係の調査はできない場合があること、対応の内容・結果は知らせられない場合があることを、フォームと自動返信で先に伝える。
6. **記録を残し、傾向で動く。** 個別の真偽より、「同じページに複数の報告」「同じ掲載者に繰り返し」を記録から見て判断する。

## 2. 問題報告の判断表（P60-13 の理由ごと）

| 理由 | 対象 | 優先度 | 既定の対応 |
|---|---|---|---|
| **プライバシーに関わる** | クリエイター・ギャラリー | **至急** | **確認より先に一時非公開**にする。そのあと掲載者に連絡し、事情を確認する（連絡＝P90-9 のテンプレート RP-02、結果＝RP-03 再公開／RP-04 非公開を続ける）。事実を確かめられなくても、本当であれば至急対応すべき問題のため（実例：ストーカー被害のため一切のウェブでの露出を避けたいという依頼）。 |
| 無断掲載・権利侵害 | 全種類 | 高 | **掲載者に照会**し、反論の機会を与える。期限内（原則7日）に反論がなければ非公開にする。反論があれば、双方の主張を記録し、明らかな権利侵害でない限り掲載を続ける（法的な請求は 4. へ）。権利を持つ本人からの申し立てか（本人／代理人／第三者）で扱いを分ける。 |
| なりすまし・虚偽のプロフィール／情報 | クリエイター・ギャラリー | 高 | 本人確認の手がかり（公式サイト・SNS 等）と照らし、なりすましが明らかなら非公開。判断できなければ掲載者に照会する。 |
| 誹謗中傷・攻撃的な内容／個人情報の掲載 | レビュー | 高 | 規約の例に当たれば非公開。個人情報の掲載は確認より先に非公開。 |
| 不適切な表現・画像 | レビュー以外（レビューは「誹謗中傷・攻撃的な内容」で受ける） | 中 | 規約の例に**明らかに**当たれば非公開。判断が分かれるものは掲載を続け、記録する。 |
| スパム・宣伝目的 | 全種類 | 中 | 削除する。繰り返す掲載者はアカウントの対応を検討する。 |
| 情報が事実と異なる | 作品・記事・レビュー | 低 | 掲載者に確認を依頼する（作品・記事は修正依頼の窓口を持たないため、ここで受ける）。 |
| その他・内容があいまいなもの | 全種類 | 低 | 受付の控えのみ。記録して、同じ対象への報告が重なったら見直す。 |

- 展覧会・クリエイター・ギャラリーの**掲載情報の誤り**は、問題報告ではなく修正依頼（P60-14）で受ける（P60-13 の展覧会の理由に「事実と異なる」は無い）。
- 「非公開」は削除ではない。対応を取り消せるよう、非公開の理由と日時を記録する。
- 掲載者への照会・連絡では、**報告者の個人情報は伝えない**。

## 3. 掲載の対象者からの削除依頼

会場・ギャラリー・クリエイター本人など、**掲載内容に登場する当事者**から「掲載を消してほしい」と求められた場合（修正依頼・問題報告・メールのどの経路で来ても同じ扱い）。

### 3-1. 何を消してほしいのかを切り分ける

| 区分 | 例 | 扱い |
|---|---|---|
| **公開の事実** | 「このギャラリーで、この展覧会が開かれた」という記録／会期・会場 | **原則削除しない**。公開されたイベントの記録で、事実である以上残すのが筋。 |
| **本人の持ち物** | ロゴ、写真、紹介文（本人のサイトからの転載）、連絡先、営業時間などの本人が管理する情報 | **求められたら外してよい**。本人に権利や管理の正当な理由があるため。 |

- 「全部は消せないが、ここはお応えできる」と伝えることで、全面対立を避ける。
- 例外：無断掲載と判断された場合、プライバシーに関わる事情がある場合（2. の判断表どおり）。展覧会はこの例外を画面で案内していない（P60-14）。

### 3-2. ページの管理権を案内する

- オーナー未設定のページ（クリエイターからの掲載依頼などで事務局が先に作ったギャラリー・クリエイターページ）なら、**「ギャラリー機能（クリエイター機能）を申し込めば、このページをご自身で管理できます」と案内する**。オーナー未設定ページの引き継ぎの仕組み（機能申込時の任意申告＋事務局による差し替え）を使う。
- 管理権を得ても**公開の事実（開催された展覧会の記録）は残る**。紹介文・写真・連絡先などは本人が直せる。
- 相手の不満の芯は「自分のことが知らないところで書かれている」ことが多く、管理できる立場を渡すとそれが消える。申し込まないのは相手の選択で、こちらは道を用意したことになる。
- **画面上の入口**：修正依頼（P60-14）・問題報告（P60-13）の中で、クリエイター・ギャラリーのとき「このページのご本人の方へ」から機能申込（元のページを引き継いだ状態）へ案内している。ページ本体には入口を置かない（閲覧者にページの出どころの印象を与えないため）。申込の事務局あて通知（M-01A／M-03A）に、申込者が名乗ったページの URL が載る。オーナーがいるページへの申込は、申込者に有無を伝えずに確認する。

### 3-3. 当事者間の揉め事

- 掲載者（例：掲載依頼したクリエイター）と対象者（例：会場のギャラリー）の間に揉め事がありそうでも、**それを判断の材料にしない**。どちらかの肩を持った時点で、サイトが揉め事の当事者になる。
- 事実の確認は「開催されたか・会期・会場」など掲載内容の範囲にとどめる。

### 3-4. レビューの削除依頼（展覧会の出展者・ギャラリーなどから）

- レビューは来場者の感想。**内容に同意できないこと（否定的な評価）だけを理由には削除しない**。
- 非公開にするのは、2. の判断表で規約に当たる場合（誹謗中傷・攻撃的な内容／個人情報の掲載／事実と異なる内容など）だけ。
- 公開ページ P60-16「掲載の削除について」にも同じ線を書いている。

### 3-5. お問合わせ（P60-11）に掲載内容の苦情・削除要求が届いた場合

- お問合わせは返信する窓口（質問への回答が対応そのもの）で、掲載内容への苦情や削除の要求を受ける窓口ではない。
- 返信で、修正依頼（P60-14）・問題報告（P60-13）の窓口と、掲載内容に関する対応方針（P60-16）を案内し、**返信はそこで区切る**（内容への判断や交渉はお問合わせのやり取りで行わない）。
- 窓口を分けても、返信がほしい人ほどお問合わせに集まるため、P60-11 の導入文は「質問・サイトの不具合」に絞っている（2026-09-27）。

### 3-6. 脅し文句（「削除しなければ通報する」等）がある場合

1. **扱いは変えない。** 脅しがあってもなくても、3-1〜3-3 の方針どおり。
2. **返信は一度、落ち着いた定型文で。** 方針（事実の記録は削除しない／本人の持ち物は外せる／管理権の案内）を伝える。
3. **正式な窓口を差し出す。** 「法的な権利侵害をお考えの場合は、所定の手続き（送信防止措置の依頼）をご案内します。その場合は法令に沿って対応します」。反論で押し返すより、正式な手続きを示す方が効く。根拠があれば手続きに乗り、なければそこで止まる。
4. **やり取りはすべて記録する。** 同じ主張の繰り返しには、方針を伝えた時点で返信を打ち切ってよい。
5. **実際に正式な通知（弁護士名の書面・法令に基づく送信防止措置の依頼など）が届いたときだけ**、専門家に相談し、法令の手続きに沿って対応する。

## 4. 法的な請求への対応（概要）

- 権利侵害を理由とする送信防止措置の依頼は、法令（プロバイダ責任制限法など）の手続きに沿う：**掲載者への照会 → 期限内（原則7日）に反論がなければ措置**、反論があれば双方の主張を踏まえて判断。
- 発信者情報の開示請求は、法令の手続きによる。事務局の判断で開示しない。
- 運用前に専門家に確認し、必要なら本節を更新する。

## 5. 画面・メールでの期待値の伝え方（反映先）

- **修正依頼（P60-14・反映済み）**：「送信いただいた内容は事務局で確認し、対応します。内容によっては、ご依頼に沿えない場合があります。個別の対応結果についてはご返信できない場合があります。掲載の削除のご依頼は、原則としてお受けしていません。（クリエイター・ギャラリーのみ：ただし、無断で掲載されている場合や、プライバシーに関わる事情がある場合は問題を報告するから）」
- **問題報告（P60-13・反映済み）**：注記「ご報告いただいた内容は事務局で確認し、利用規約に基づいて対応します。事実関係の調査はできない場合があります。また、対応の内容や結果についてはお知らせできない場合があります。対応の考え方は掲載内容に関する対応方針をご覧ください。」。自動返信 F-03 も同じ趣旨。「対象との関係（本人／代理人／第三者）」「問題の箇所」の入力欄の追加は未実施（検討）。
- **事務局あて通知（F-03A・反映済み）**：件名に理由で決まる優先度の印（プライバシーに関わる＝【至急】）、本文に 2. の判断表。
- **回答テンプレート（P90-9・反映済み）**：修正依頼は FX-01〜FX-05、掲載の対象者からの削除依頼（3.）は RP-01（使用画面＝問題報告）。
- **公開用の対応方針ページ（P60-16「掲載内容に関する対応方針」・反映済み）**：本ファイルの要約。基本の考え方／ご連絡方法／問題のご報告への対応／掲載の削除について／法令に基づくご請求／お問合せ（画面の見出しどおり）。内部の判断表のうち「照会の期限」「非公開の具体的な基準」などは載せない。P60-13・P60-14 の注記からリンク。
