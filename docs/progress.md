**表示系ページのセクション間マージンを共通クラス `.ktn-csec` に一元化（p2〜p5-4）✓実装済・ブラウザ確認待ち**

- **目的**：メインカラムの「セクション箱どうしの縦間隔」がページごとに別々のクラス・別々の値で散らばっていたのを、単一ソース `--section-gap`（`:root` L62 ＝ **40px**）＋共通クラス **`.ktn-csec`**（common.css L12448 `margin-bottom:var(--section-gap)`）に集約
- **方針（ユーザー選択）**：**マージンのみ共通化**。各ページ固有のセクションクラス（箱・見出しの見た目）はそのまま残し、その要素に `.ktn-csec` を**併記**するだけ。クラスを強制統合はしない。`.ktn-csec` は各固有クラスの `margin-bottom` より**後段（L12448）**にあるため、同詳細度・ソース順で `.ktn-csec` が勝つ（＝40pxに統一。旧 56px/10px/0px 等を上書き）
- **旧メカニズムの撤去**：L12440 にあった `.p2-layout > section + section, .p2-layout__main > section + section, .p3-main > section + section { margin-top:8px }` を削除（`.p3-main` は実在せず・`+section` 隣接指定は箱の間に非section要素が挟まると崩れる）。`.p2-layout{gap:0 28px;padding-top:32px}` は保持
- **適用済み（`.ktn-csec` を併記した箱）**：p2（`.p2-about`×1・`.p2-ic`×3）／p2-1（`.p2-1-section`×4）／p2-2（`.p2-2-section`×3）／p2-3（`.p2-3-section`×5）／p3（`.p2-ic` メイン×3。サイドの `#p3-sec-articles` は除外）／p4（`.p4-box`×2）／p5-1（`.p5-1-section`×3）／p5-4（`.p54-section`×1）
- **除外と理由**：①**p2-5/p2-5-1** はメインが全幅カラーバンド（`.p2-5-about`/`.p2-5-works`＝背景色＋border-bottom 区切り）で「箱の積み重ね」ではない。バンドに margin を足すと区切りデザインが崩れる。唯一の箱 `.p2-ic`（出品クリエイター）は `.p25-layout` メイン内で単独＝隣に間隔をとる兄弟がないため対象外 ②一覧系（p3-1〜3/p4-1〜2/p5-2〜3 等）は単一コンテンツブロックで縦積みセクションを持たないため対象外
- **各固有クラスの `margin-bottom` は fallback として残置**（`.ktn-csec` が付かない箇所での従来値を維持。将来クリーンアップは任意・低優先）
- **後工程（React CSR）**：セクション箱の外側ラッパを単一 `SectionWrapper`（`.ktn-csec` 相当・`--section-gap` 参照）に寄せられる。各ページ固有の箱/見出しコンポーネントは温存
