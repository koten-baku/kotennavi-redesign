# タグバーと「タグ」の欄（後工程向けの説明）

最終更新：2026-10-14（タグバーの作り直しの確定時に作成）

表示系のページにある、上の **タグバー**（ヘッダーの下の一行）と、ページの下の **「タグ · Tags」の欄** の仕様です。React CSR／Drupal に移すときは、この文書から読んでください。

- 制作ルールの正本は `CLAUDE.md`「タグバー（`.ktn-tagbar`）と、ページの下の『タグ』の欄」。この文書はその詳しい説明で、食い違ったら CLAUDE.md を正とします。
- 決めた経緯と理由は `handoff-decisions.md` 追174-322（索引「タグバー・ページのタグ」）。
- プロトタイプの実装：`kotennavi-common.js` の「ページのタグ」のまとまり（`PAGE_TAGS` から `KTN.setPageTags` まで）、`kotennavi-pages.js`（作品 P6・記事 P7・4つの検索の受け口・記事一覧 P3-2／P4-2）、`kotennavi-common.css`（`.ktn-tagbar`）。

---

## 1. 目的

**いま表示しているコンテンツと似ているほかのコンテンツを、もっと見てもらうための道具。** 利用者の便利さを上げることと、コンテンツ（展覧会・作品・クリエイター・ギャラリー）の露出を上げることが目的です。

そのため、タグバーに載せる言葉は次の決まりを守ります。

- **表示しているページに関係がある、またはタグ付けされている言葉だけ**を載せる。
- **押すと、そのページへ移るか、検索（P10 系）でその条件の一覧が開く**。押しても何も起きない言葉は載せない。
- ページの中の移動や、兄弟ページへの移動は載せない（サブナビ・タブナビの役割）。

---

## 2. 上のタグバーと、下の「タグ」の欄

両方を置きます。中身は **同じデータから出し、同じ並び**です。

| | 上のタグバー | 下の「タグ」の欄 |
|---|---|---|
| 役割 | ページに来たときの手がかり（このページがどんなものか、似たものがどこにあるか） | 読み終えて関心が高まったときの、次の行き先（回遊） |
| 形 | 一行。収まらないときは横に送る | 折り返して全部を出す |
| 位置 | ヘッダーの下。ページと一緒に流れる（ヘッダーに固定しない） | ページの下（関連・回遊のゾーン） |

上をヘッダーに固定して下をなくす案は採りませんでした。ヘッダー・タブナビと固定する帯が重なり、本文の見える高さが減るためです（特にスマホ）。

## 3. 出すページ・出さないページ

**出すページ（19ページ）**

| 系統 | ページ | 行き先の検索 |
|---|---|---|
| 展覧会 | P2・P2-1〜P2-5・P2-5-1 | 展覧会 P10（ゲストも使える） |
| クリエイター | P3・P3-1〜P3-3 | クリエイター P10-2（ログインが要る） |
| ギャラリー | P4・P4-1・P4-2 | ギャラリー P10-3（ログインが要る） |
| 作品 | P6・P6-1・P6-2 | 作品 P10-1（ログインが要る） |
| 記事 | P7 | 元のページと同じ（下の 4.5） |
| レビュー | P8 | 展覧会 P10 |

- **下位ページは親と同じタグ**を出します（P2-1 → P2、P3-1 → P3 など）。下位ページ用の定義は作らず、親が下位ページの分まで受け持ちます。
- 例外として、作品は P6・P6-1・P6-2 で少しずつ違います（4.4）。同じ作品でも、LIAISON の有無で載せる言葉が変わるためです。

**出さないページ**：P10 系（検索・特集・ランキング＝絞り込みそのものがページにある）、P1、P5 系（myページ）、ガイド、お知らせ、管理・編集のページ。載せるタグが1つも無いページでは、タグバーごと出しません。

## 4. 各ページで出すもの

タグは2種類あります。

- **サイトが決めた条件**：開催の状態、エリア、ジャンル、行きやすさ、販売の状態など。サイトが持つ決まった選択肢から選ばれるもの。
- **自由入力のタグ**：登録する人が編集画面で自由に入れた言葉（絵画・油彩・オノマトペなど）。**技法・素材も含めて、タグはすべて自由入力**で、決まった一覧はありません。

どちらも、**そのコンテンツに当てはまるものだけ**を載せます。下の表は「載せうるもの」の一覧です。

### 4.1 展覧会（P2 系）・レビュー（P8）

レビューは、対象の展覧会と同じタグを出します。

| 区分 | 載せる言葉 | 載せる条件 |
|---|---|---|
| 開催の状態・期間 | 開催中・今日・今週末 | 会期中のとき |
| | 今日から開催 | 初日のとき |
| | もうすぐ開催 | 開幕まで3日以内 |
| | もうすぐ終了 | 終わりまで3日以内 |
| エリア | 都道府県、東京6エリア（東京西部 など） | 会場の所在地 |
| ジャンル | アート・写真・クラフト・建築・ファッション | 特集のページがあるジャンルのとき（展覧会の検索にジャンルの条件が無いため） |
| 形式 | 個展／グループ展 | |
| 行きやすさ | お子さまと行ける・在廊あり・入場無料・バリアフリー・駐車場あり・クレジットカードOK・来場者特典あり・会場での作品販売あり | 当てはまるものだけ |
| 人気・新着 | 人気の展覧会／新着 | 検索の「人気」「新着」と同じ基準で当てはまるとき |
| LIAISON | LIAISON／LIAISON+ | 使っているとき |
| 人 | 会場のギャラリー、出展クリエイター | 4.6 |
| 自由入力のタグ | # 絵画、# オノマトペ など | 付いているもの全部 |

- 「今日から開催」「もうすぐ開催」「もうすぐ終了」の境目（3日）は、**展覧会の検索と同じ値**を使います（プロトタイプは pages.js `SOON_DAYS`）。タグ側で別の日数を持つと、押した先の一覧にその展覧会が出なくなるためです。
- 会期の前で開幕まで3日より先のとき、会期が終わったあとは、期間の言葉を出しません。
- 新着は、公開日から14日以内です（サイト共通の基準 `KTN.NEW_DAYS`・CLAUDE.md「新着と NEW の印」）。
- 街の名前（渋谷・銀座など）は、場所のデータに無いので使いません。場所は47都道府県と東京6エリアだけです。

### 4.2 クリエイター（P3 系）

| 区分 | 載せる言葉 | 載せる条件 |
|---|---|---|
| 開催の状態 | 開催中／開催予定 | そのクリエイターの展覧会が開催中／予定にあるとき |
| ジャンル | アート など（6区分） | |
| LIAISON | LIAISON+ | 使っているとき |
| 自由入力のタグ | # 絵画 など | |

**エリアは持ちません**（クリエイターには活動のエリアのデータが無いため）。

### 4.3 ギャラリー（P4 系）

| 区分 | 載せる言葉 | 載せる条件 |
|---|---|---|
| 開催の状態 | 開催中／開催予定 | そのギャラリーの展覧会が開催中／予定にあるとき |
| エリア | 都道府県、東京6エリア | ギャラリーの所在地 |
| ジャンル | アート など | |
| 設備 | バリアフリー・駐車場あり・クレジットカードOK・レンタルギャラリー | 当てはまるものだけ |
| LIAISON | LIAISON+ | 使っているとき |
| 自由入力のタグ | # 現代美術 など | |

### 4.4 作品（P6 系）

| 区分 | P6（通常） | P6-1（LIAISON） | P6-2（LIAISON+） |
|---|---|---|---|
| ジャンル | ○ | ○ | ○ |
| 販売の状態（販売中・商談中・要問合せ・SOLD・非売品） | — | ○ | ○ |
| 価格帯（〜5万円・5〜10万円・10〜30万円・30万円〜） | — | — | ○ |
| LIAISON | — | LIAISON | LIAISON+ |
| 人（作者・出品者） | ○ | ○ | ○ |
| 自由入力のタグ | ○ | ○ | ○ |

- 価格帯は P6-2 だけです。作品の検索では、価格帯は LIAISON+ の条件と一緒のときだけ効くためです。そのため、価格帯のタグは **LIAISON+ の条件も付けて**検索へ飛ばします（`?f=price:30-&f=liaison:lp`）。
- 制作年・号数・SOLD などは作品の仕様の欄に出ているので、自由入力のタグからは外します。

### 4.5 記事（P7）

**掲載先のページのタグと、投稿者のページのタグを合わせたもの**に、その記事だけのタグを足します。

| 記事の種類 | 掲載先 | 投稿者 |
|---|---|---|
| 作品についての記事 | 作品（P6 と同じ） | クリエイター（P3 と同じ）またはギャラリー（P4 と同じ） |
| 展覧会についての記事 | 展覧会（P2 と同じ） | 同上 |
| クリエイターの記事 | クリエイター（P3 と同じ） | 同じなので1回だけ |
| ギャラリーの記事 | ギャラリー（P4 と同じ） | 同じなので1回だけ |

- 各タグの行き先は、元のページと同じです（作品のタグは作品の検索へ、クリエイターのタグはクリエイターの検索へ）。記事には専用の検索が無いためです。
- 両方のページにある言葉（アート・# 絵画 など）は、掲載先のものを1つだけ残します。
- **記事だけのタグ**（# 制作日記・# 展評・# インタビュー など）は、記事の検索が無いので、**投稿者の記事一覧（P3-2・P4-2）をそのタグで絞って**開きます（`?tag=制作日記`）。同じ人の別の記事へつながります。

### 4.6 人のタグ

押すと、その人のページへ移ります（検索ではありません）。個人のページはゲストも見られるので、ログインは求めません。

| ページ | 出す人 |
|---|---|
| 展覧会・展覧会についての記事・レビュー | 会場のギャラリー（いつも名前）、出展クリエイター（下の決まり） |
| 作品・作品についての記事 | 作者（クリエイター）と出品者。違う人なら両方、同じ人なら1つ |

**出展クリエイターの決まり**：3人までなら全員の名前を出します。4人以上のときは名前を出さず、「出展クリエイター（N人）」を1つだけ出して、出展者のページ（P2-4）へ飛ばします。

理由：出展者が3桁になる展覧会があり、誰を優先して載せるかをシステムが決められません。一部の人だけを載せる不公平も起こしません。代表のクリエイターを主催者に選ばせる案は、入力の手間と選ぶ基準で揉めやすいため採りませんでした。人数の境目は `KTN_PEOPLE_MAX`（3）です。

## 5. 並び順

**大事なものほど前に置きます。** 一行に収まらないとき、後ろのタグは画面の外に隠れるためです。

1. 開催の状態・期間（開催中・今日・今週末／もうすぐ開催 など）
2. エリア
3. ジャンル
4. 形式（個展／グループ展）
5. 販売の状態・価格帯（作品）
6. 行きやすさ・設備
7. 人気・新着
8. LIAISON／LIAISON+
9. 人（会場のギャラリー・出展クリエイター／作者・出品者）
10. **自由入力のタグ（# の付くもの）**：サイトが決めた条件のあとに、まとめて置く

- 記事（P7）は、掲載先のページの並び → 投稿者のページの並び。そのうえで、自由入力のタグは全体の最後にまとめます。
- 並びは表示するときにそろえます（プロトタイプは `ktnTagOrder`）。データの順番に頼らないでください。

## 6. 押した先（行き先）

| タグ | 行き先 |
|---|---|
| 特集のページがある言葉 | **特集のページ**（ゲストも見られ、検索エンジンに載る一覧）。展覧会：エリア → P10-4-2（`?ax=`）、ジャンル → P10-4-4（`?gn=`）、お子さまと行ける・在廊あり → P10-4-5（`?ac=`）。ギャラリー：エリア → P10-7-2（`?ax=`） |
| そのほかの条件・自由入力のタグ | 種別の検索に、その条件を付けて着地（`./kotennavi-{検索}.html?f=キー:値`。複数なら `f` を重ねる） |
| 人 | その人のページ（P3・P4）、または出展者のページ（P2-4） |
| 記事だけのタグ | 投稿者の記事一覧（P3-2・P4-2）を `?tag=` で絞る |

**ゲスト**：作品・クリエイター・ギャラリーの検索はログインが要るので、そこへ飛ぶタグには `data-guest="login"` を付け、ゲストにはログインを促します（ログイン後に元の操作を続けられる共通の仕組み `KTN.action.show`）。特集のページ・人のページ・展覧会の検索へ飛ぶタグには付けません。

**検索の受け口**：4つの検索（P10・P10-1・P10-2・P10-3）は、URL の `?f=` で条件を受けて点けます。自由入力のタグが検索の選択肢に無い言葉でも、選択肢に足してから点けます（`KTN.urlTags`）。点いた条件は絞り込みの表示に「# オノマトペ ×」と出て、× で外せます。記事一覧（P3-2・P4-2）も同じく「# 制作日記 ×」を出します。

**キー**（検索のページの `data-f` と同じ）

| キー | 値 | 意味 |
|---|---|---|
| `st` | `live`・`upcoming` | 開催中・開催予定（展覧会・クリエイター・ギャラリー） |
| `st` | `sale`・`negot`・`inquiry`・`sold`・`nsale` | 販売中・商談中・要問合せ・SOLD・非売品（作品） |
| `day` | `月.日` | その日に開催（「今日」） |
| `weekend` | `1` | 今週末 |
| `when` | `opentoday`・`opensoon`・`endsoon` | 今日から開催・もうすぐ開催・もうすぐ終了 |
| `area` | 都道府県名 | エリア |
| `tarea` | 東京6エリアの名前 | 東京のエリア |
| `genre` | 6区分の名前 | ジャンル |
| `tag` | 言葉 | 自由入力のタグ |
| `type` | `solo`・`group` | 個展・グループ展 |
| `liaison` | `li`・`lp` | LIAISON・LIAISON+ |
| `price` | `~5`・`5-10`・`10-30`・`30-` | 価格帯（万円・作品） |
| 行きやすさ | `kids`・`attend`・`free`・`barrierfree`・`parking`・`card`・`bonus`・`onsite`・`rental`（値は `1`） | 行きやすさ・設備 |
| `pop`・`new` | `1` | 人気・新着 |

## 7. 見た目

- **先頭に見出し「Tags」**（Cinzel の大文字）。タグだと分かるように付けています。横に送っても動きません。スマホでも出します。
- タグは枠つきの丸い形で、**どのタグも同じ形と色**です（LIAISON／LIAISON+ も特別な形にしません）。
- **自由入力のタグにだけ先頭に「# 」**を付けて、サイトが決めた条件と見分けます。検索の選択肢「# 絵画」や、絞り込みの表示「# オノマトペ ×」と同じ書き方です。現行サイトは自由入力のタグの色を少し変えていますが、色だけの差は気づかれにくいので、記号で見分ける形にしました。
- 上のタグバーでは、エリアのタグの先頭にピンの印を付けます。
- 見出し・矢印・タグの列は、本文と同じ左端（ページの幅・左右20px）にそろえます。
- **一行に収まらないとき**
  - 左右に矢印（‹ ›）を出します。はみ出しているときだけ出し、端まで送った側は消します。1回で 160px 送ります。
  - はみ出している側の端を白くぼかして、続きがあることを見せます。
  - スマホなど指で送れる端末では、矢印を出さず、ぼかしだけにします。
  - 矢印は共通の処理が自動で付けます。各ページの HTML に書きません。
- 管理・編集のページでは、タグバーを出しません。

## 8. タグの入力（編集画面）

展覧会（P2-11）・作品（P6-11）・記事（P7-11）の編集画面のタグは、自由入力です（入力して Enter）。

- **すでに使われているタグを候補に出します**（ブラウザの候補リスト＝datalist）。候補に無い言葉も、そのまま追加できます。
- 目的は表記のゆれ（油彩／油絵 など）を減らすことです。同じ意味の言葉がそろうと、押した先の一覧に似たものがまとまって出ます。
- 説明文に「候補に出ること」と「押すと同じタグの一覧につながること」を書いています。
- 本番では、候補を実際に使われているタグから、使われている数の多い順に出してください（プロトタイプはデモの一覧）。

## 9. 後工程で作るもの

| 項目 | 内容 |
|---|---|
| タグのデータ | 各コンテンツのデータから出す。プロトタイプの `PAGE_TAGS` の値はデモ |
| 当てはまる判定 | 開催の状態・期間は会期の日付から、人気・新着は検索と同じ基準から、行きやすさ・設備・LIAISON・販売の状態・価格帯はそれぞれのデータから決める。**検索と同じ判定を使う**（タグと検索で基準がずれると、押した先にそのコンテンツが出ない） |
| 人のタグ | 会場のギャラリー、出展クリエイター（人数で出し方を変える）、作品の作者と出品者 |
| 検索の受け口 | 4つの検索で、`?f=` の条件（複数可）を受ける。自由入力のタグは、選択肢に無い言葉も受ける |
| 記事一覧の受け口 | P3-2・P4-2 で `?tag=` を受けて絞る |
| タグの候補 | 編集画面で、使われているタグを数の多い順に候補に出す |
| 「今日」の値 | 当日の日付。プロトタイプは検索のデモの今日（07.08）に合わせて固定している |

**React 変換**：`<TagBar tags search>`（上）と `<PageTags tags search>`（下）に、同じ `tags` を渡す。

### プロトタイプでの注意

- 検索のデモデータには「オノマトペ」などの自由入力のタグを持つ展覧会・作品が無いので、押した先は0件になります（条件は点きます）。
- P7 のデモの展覧会についての記事は、P2 のデモ（会期中）と同じタグを出すので、「開催中・今日・今週末」が出ます。記事の中の会期の表示とは合っていません。本番は展覧会の会期から決まります。
