# 個展なび - サービス概要（既存サイト）

## サービス基本情報
- **サービス名**: 個展なび
- **URL**: https://koten-navi.com/
- **種別**: 展覧会情報ポータルサイト

## サービス目的・コンセプト
全国各地で開催される展覧会の情報を集約し、より多くの人に展覧会へ足を運んでもらうためのプラットフォーム。

**2つの目的**
1. 鑑賞者が展示・作品に触れることで自らのセンスが磨かれる場を提供する
2. 大企業の資本の恩恵を受けにくい個人ベースのクリエイター・ギャラリーをサポートする

**コンセプト**
- 中立性（専門家の批評を排除）
- 自律性・自発性（開催者が自ら情報発信）
- 独自性（既存サイトにないサービスを提供）

## ユーザー種別と機能

| ユーザー種別 | 主な機能 |
|---|---|
| ユーザー | ウォッチ（クリエイター・ギャラリー）、興味あり！（展覧会・作品・記事・レビュー）、チェックイン（展覧会） |
| ユーザー＋クリエイター | 上記＋クリエイターページ所有、展覧会掲載、作品掲載 |
| ユーザー＋ギャラリー | 上記＋ギャラリーページ所有、展覧会掲載 |

**関連付け**: クリエイター・ギャラリー・ユーザーは「展覧会」を通じて相互に関連付けられる

## リデザインの背景・課題
- 新サービス「リエゾン」導入により、サイト内の多くのページが影響を受ける
- SEO対策の強化が必要
- 回遊性の向上が必要
- UI/UX全体の改善
- 新サービス「リエゾン」がより活用されるサイト設計にしたい

## 技術スタック
- **バックエンド**: Drupal
- **フロントエンド**: React（SSR）
- **納品形式**: HTML / CSS / JS ファイル
