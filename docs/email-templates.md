# 自動送出メール文面集（個展なび）

サイトからユーザーへ自動送出するメール（申込受付・機能付与完了・取引各フェーズ通知 等）の**文面の単一ソース**。UI と同じく「捕捉は決定時、構造化は後」の原則で、確定した発火点から順に文面を起こして追記していく（完成後にまとめて作らない）。

## 位置づけ・進め方

- **本番実装は Drupal（バックエンド）が送出**する。本ファイルは Drupal 実装フェーズへ渡す**文面と発火条件の仕様**であり、HTML/CSS のメールテンプレート実装そのものではない。
- **まずプレーンテキスト文面を確定する**。装飾HTMLメール化は Drupal フェーズで別途行う（プレーンが常に fallback として要るため先に固める）。
- 文面中の可変値は **`{{token}}` プレースホルダー**で書く（下記「トークン規約」）。
- 1通ごとに「発火点／受信者／トリガー／件名／本文」をワンセットで書く。**発火点の棚卸し（下表）が index、各文面が本体**。
- サイト内の状態名・期限呼称・ページ呼称は **CLAUDE.md / docs/transaction-states.md が canonical**。メール文面もそれに従い、独自の言い換えをしない（例：状態名「購入確定待ち」、期限呼称「確定期限」）。

## 追記時のルール

- 新しい発火点が確定したら、まず上の**インベントリ表に1行追加**（状態＝未着手）。文面を起こしたら「起草済」に更新し、本文セクションを追記する。
- 状態名・期限・ページ呼称は CLAUDE.md / transaction-states.md を参照し、**メール独自の言い換えをしない**。
- 画面（`KTN.submitDone()` モーダル・`.ktn-txn-alert` 等）とメールで、同じイベントの表現・期限値を食い違わせない。
- Drupal 実装フェーズで、共通ヘッダー/フッター部品・トークン差し込み・HTMLメール化を行う。本ファイルはその入力仕様。
