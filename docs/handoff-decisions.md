- 詳細を重複転記しない。CLAUDE.md / docs の該当箇所を指す。

- `docs/progress.md` を更新するのと同じタイミングで、関連する決定を本ファイルにも追記する。
- 新しい共通コンポーネント確定時は「3. コンポーネント → React」に1行追加。
